# A股短线情报 Agent

这是一个可部署到 GitHub Pages 的静态网页原型。

## 文件

- `index.html`：网页主文件，手机和电脑都可以打开。

## GitHub Pages 部署方式

1. 新建 GitHub 仓库，例如 `a-share-news-agent`。
2. 把 `index.html` 上传到仓库根目录。
3. 打开仓库 `Settings` -> `Pages`。
4. Source 选择 `Deploy from a branch`。
5. Branch 选择 `main` 和 `/root`。
6. 保存后等待 GitHub 生成网页链接。

## 产品边界

当前版本是前端原型，用于展示 A 股短线新闻驱动分析流程，不构成投资建议。
